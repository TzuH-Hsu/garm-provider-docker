# Code of Conduct

This project follows the
[Contributor Covenant, version 3.0](https://www.contributor-covenant.org/version/3/0/code_of_conduct/).

It applies in this repository's issues, pull requests and Discussions, and
wherever someone represents the project.

To report a problem, email conduct@tzuhsuan.dev. The maintainer reads reports
and keeps them confidential. If your report is about the maintainer, use
GitHub's [report abuse](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam)
process instead.
