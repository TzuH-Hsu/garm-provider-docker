# Getting help

- **Questions and setup help:** [Discussions](https://github.com/TzuH-Hsu/garm-provider-docker/discussions).
- **Bugs:** [open an issue](https://github.com/TzuH-Hsu/garm-provider-docker/issues/new/choose).
- **Security problems:** see [SECURITY.md](SECURITY.md).
- **GARM itself:** [cloudbase/garm](https://github.com/cloudbase/garm).

Start with the [README](README.md) and the
[configuration reference](docs/config-reference.md).

When you ask for help, include:

- provider and GARM versions, and the `interface_version` you set
- pool or scale set, and the `dind_mode`
- host OS, architecture, Docker Engine version and storage filesystem
- the provider and GARM log lines around the failure, with secrets removed

This is a one-maintainer project with no support commitment. Replies are best
effort.
